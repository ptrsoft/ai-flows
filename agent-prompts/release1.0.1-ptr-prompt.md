## Evaluation Checklist

For each response, check:

1. **Structure Compliance**
   - [ ] Follows correct template
   - [ ] Includes all required sections
   - [ ] Proper formatting (bullet points, numbering)

2. **Content Quality**
   - [ ] Information from knowledge base
   - [ ] Professional tone
   - [ ] Clear explanations
   - [ ] Appropriate technical depth

3. **Error Handling**
   - [ ] Proper handling of unknown topics
   - [ ] Clear clarification requests
   - [ ] Helpful alternative suggestions

4. **Follow-up**
   - [ ] Offers additional information
   - [ ] Suggests related topics
   - [ ] Provides next steps

## Response Evaluation Notes

1. **Technical Questions**
   - Should provide specific, actionable information
   - Should include implementation details
   - Should reference documentation

2. **Error Resolution**
   - Should provide step-by-step solutions
   - Should include prevention tips
   - Should offer escalation paths

3. **Unknown Topics**
   - Should acknowledge limitations
   - Should suggest related topics
   - Should maintain helpful tone

4. **Clarification Requests**
   - Should ask specific questions
   - Should explain why clarification is needed
   - Should guide user to provide better information
